# SOXAI Ring X 调研报告

Oct 10, 2026 · @Will

项目秘书（A12）整理，供维真 Vera 项目组讨论。

## 一、结论先行

SOXAI Ring X 是日本 SOXAI 公司的第 5 代智能戒指：宽 5.19 mm、厚 2.6 mm、最长续航 10 天，计划零售价 399 美元，2027 年 5–7 月交付。它只讲一件事：“戴着忘了它在”。

**对维真 Vera 的四条启示**

1. **新加坡会正面相遇，中国暂时不会。** Ring X 计划认证的市场包括新加坡，但不含中国大陆。上海、北京首发没有它的直接竞争，新加坡要做好 2027 年中与它同场的准备。
2. **“小”的赛道已被占住。** 它已经四次宣称“世界最小”，并把“尺寸—续航之墙”做成了叙事核心。Vera 应把参数当底线而不是卖点，差异化放在文化内核、节气与 ECG / NFC。
3. **App 全功能免费，会员模式要经得起对比。** Ring X 承诺所有功能（含未来更新）免费，个人 API / SDK 也免费。维真的“元气+”会员需要说清楚付费买到了什么。
4. **“不测什么”也是信任。** 它主动声明不测血糖、不测血压，并把这写成科学伦理。这与《维真 Vera 设计理念》“不估血压、不估血糖”一致，可以借鉴这种说法。Ring X 没有 ECG 和 NFC，这是 Vera 的机会，但 ECG 必须拿到注册证才能宣称。

## 三、众筹表现与叙事

众筹 72 小时筹到 63.52 万美元、支持者 2,868 人（[SOXAI 新闻稿](https://www.newswire.ca/news-releases/soxai-ring-x-tops-us-635-200-in-kickstarter-pledges-attracts-2-868-backers-in-first-72-hours-862825911.html)）。活动日本时间 2026-10-02 至 10-10，今天结束，最终数字尚未公布。另有报道称几天内超过 75 万美元，未核实。

**销售策略**

- 只选数量，不选尺码和颜色；众筹后先寄试戴套装，再确认尺码。
- 早鸟价限量先到先得；多枚套装单价更低，鼓励与家人朋友分享。
- 全球免运费；在未认证的国家全额退款。

**叙事结构**（按页面顺序）

1. 三次“世界最小”，Ring X 是第四次。
2. “忘了你戴着它，这是唯一重要的规格”：摘下来就什么都不算数。
3. “尺寸—续航之墙”：把市面戒指画在一张图上，宣称 Ring X 是第一个越过这条线的。
4. 自研而非白牌：传感器、固件、算法、App 全自研。
5. 日本制造：研发、量产、检测、售后都在日本。
6. 不测血糖血压：把合规写成科学与工程伦理。
7. 数据归你：免费 API / SDK。
8. 可信背书：ISO 27001、东京大学合作、同行评审论文、170 多家机构在用。
9. 创始人故事：从 10 平方米的租用仓库起步。
10. 社名来自“無病息災”：一句话点到为止。

**值得维真注意的两点**：第 10 条用一个传统词轻轻交代文化来源，没有做成文化贴图，与纲领“内核不贴图”的原则相合。第 6 条把“少做”讲成信任，维真可以用同样的方式讲“不打总分”。

## 四、公司与技术背景

SOXAI 成立于 2021 年，4 年内交付 4 代戒指，核心优势是自研光学传感与日本本土量产。

| 方面 | 情况 |
| --- | --- |
| 创始人 | 渡邉達彦，工学博士（光学），曾为苏黎世联邦理工学院电磁场研究所 ETH Fellow，后在大企业做穿戴研发 |
| 公司名 | 来自日语“無病息災” |
| 市场地位 | 自称 2022–2024 年日本智能戒指 App 累计下载量第一（自家调查）；在日本大型家电卖场销售 |
| 技术 | 传感器、固件、信号处理、功耗管理、算法、App 全自研；光学传感 Deep Sensing™ 持有日本专利 |

**Ring X 开发节奏**

1. 2026 年 3 月启动开发。
2. 已完成：概念与市场验证、初始样机、工程验证（EVT）。
3. 2026 年 10 月众筹。
4. 2026 年 12 月前寄出试戴套装。
5. 设计验证（DVT）：可靠性测试、冻结规格。
6. 量产验证（PVT）：在量产工厂用量产设备试产两轮。
7. 2027 年 5–7 月交付。

从启动到交付约 14–16 个月，可作为维真排期的参照；但 SOXAI 是在已有 4 代量产线和现成 App 的基础上做的。

**认证计划**：已计划美国、加拿大、英国、欧盟 / EEA、澳大利亚、新加坡、日本，正在考虑台湾和韩国。现有 SOXAI 产品仅能在日本使用。

## 五、与维真 Vera 逐项对比

Vera 在功能（ECG、NFC）与文化内容上有差异，在尺寸、量产经验、App 成熟度上落后。Vera 一栏来自项目纲领与《设计理念》，多数参数尚未确定。

| 维度 | SOXAI Ring X | 维真 Vera | 建议 |
| --- | --- | --- | --- |
| 宽 / 厚 | 5.19 mm / 2.6 mm | 待定（厚度初步目标 ≤ 2.5–3 mm） | A5 以此为参照定底线；ECG 外圈电极和 NFC 会吃掉空间，可能难以做到同等尺寸 |
| 续航 | 最长 10 天 | 待定 | A8 按尺码分别测算，对外同样注明尺码条件 |
| 材质 / 配色 | 未写明；银、黑、金 | 钛 + 陶瓷；墨、月白、香槟金、汝窑青 | 陶瓷与汝窑青是明显差异 |
| ECG | 无 | 有，需注册证 | 核心差异；未拿证前只做非医疗展示 |
| NFC | 无 | 有 | 差异；支付需与当地机构合作 |
| 评分 | 睡眠、准备度、活动三项评分 | 元气与负荷并列，不打总分 | 叙事差异，可强调“不制造分数焦虑” |
| 文化内容 | 社名“無病息災”一句带过 | 节气三层、光漩、宋画视觉贯穿产品 | 核心差异 |
| App 收费 | 全部免费 | 元气+ 会员 | 需论证会员价值（如节气实物寄送 I-01） |
| 开放数据 | 免费 API / SDK | 未定 | B4 评估是否提供数据导出 |
| 医疗边界 | 不测血糖血压 | 不估血压血糖；注册证开关 | 一致，可借鉴其表达 |
| 制造叙事 | 日本制造全链条 | 待定 | A10 尽早定制造地与可讲的质量故事 |
| 目标市场 | 美、加、英、欧、澳、新加坡、日 | 上海、北京、新加坡 | 新加坡重叠 |
| 价格 | 计划 399 美元 | 待定 | 可作为新加坡定价参照 |

## 五之二、竞品宣传片：Ring X 品牌短片（2026-10-13 补）

这条 60 秒短片一个镜头都没给 App 和数据，只拍日本手艺人戴着戒指干精细活，把“5.19 毫米宽”讲成了“戴着也不碍事”。素材是负责人 2026-10-13 上传的视频（约 60 秒、1280×720、无台词只有配乐），按每 2 秒一帧逐帧看过。

| 段落 | 时长 | 画面 | 在讲什么 |
| --- | --- | --- | --- |
| 片头 | 约 3 秒 | 俯拍茶园，红衣人走在中间；SOXAI 标志，竖排“無病息災”和“sleep for health” | 品牌口号 |
| 前段（黑白） | 约 12 秒 | 纸格窗后的剪影、和服、跪坐 | 静、夜、睡 |
| 中段（彩色） | 约 40 秒 | 采茶、点抹茶、削竹做茶筅、拉坯、给瓷碗描金、画鱼、整理和服；每只手上都戴着戒指 | 醒来、生活、工艺 |
| 片尾 | 约 5 秒 | 竹林；“SOXAI RING X / 世界最小智能戒指 / 最长 10 天续航 · 5.19 毫米宽 · 日本制造” | 参数一屏讲完 |

**它做对的五件事**

1. 只拍“戴着它生活”，不拍功能和界面。
2. 用手艺人干精细活来证明“细”，不靠产品特写。
3. 把“日本制造”和日本匠人工艺绑在一起，戒指也就成了工艺品。
4. 黑白转彩色，对应从睡到醒。
5. 参数只在最后一屏出现，“世界最小”附了出处：依据主要厂商公开资料，截至 2026 年 8 月。

**维真的借鉴与避让**

- 借鉴：同样只拍手和生活，换成中国工艺（书法、功夫茶、古琴、苏绣、宋瓷）和 24 节气。
- 借鉴：参数一屏讲清并附依据，心电款要标明拿证情况。
- 避让：它已经占了“茶 + 竹林 + 纸格窗 + 和服”，维真不要再用竹林和纸窗做主画面，App 的竹影背景也不出现窗格，竹子按中国水墨撇叶来画。
- 合规：“無病息災”是“没病没灾”的功效暗示，在中国不能用；维真的口号只讲节律、作息、自然。

维真宣传片的分镜另见《维真 宣传片分镜（A2 草案）》。
