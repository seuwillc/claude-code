## 二、对标头部厂商

头部厂商的共同方向是三件事：AI 健康助手、“身体年龄”类长期指标、拿到注册的心脏功能。前两件维真已有（问 Vera、身体年龄），差距主要在心脏功能、饮食和收费模式。

| 厂商 | 他们的做法 | 维真现状 | 我们的不足 |
| --- | --- | --- | --- |
| Oura（Ring 5，399 美元起） | 睡眠 / 准备度 / 活动三项评分；AI 助手 Oura Advisor；用脉搏波传导速度估算“心血管年龄”；饮食与血糖功能；美国有付费问诊；会员每月 5.99 / 每年 69.99 美元 | 问 Vera、身体年龄、外接血糖仪、互联网医院入口（会员） | 没有饮食记录 |
| WHOOP（MG，订阅制） | 恢复 / 负荷 / 睡眠；Healthspan 与“WHOOP 年龄”、衰老速度；手腕心电获 FDA 批准；血压洞察为估算值，有争议 | 元气 / 负荷并列、青年模式训练建议 | 训练记录较浅；心电还没拿证 |
| 三星 Galaxy Ring（无订阅） | 能量分、AI 睡眠分；和三星手机、手表深度联动 | 无订阅的基础数据永久免费 | 生态联动弱（没有自家手机 / 手表） |
| Ultrahuman（无订阅，部分插件收费） | 恢复与活动指数；“咖啡因窗口”等小工具；PowerPlugs 插件生态 | 习惯打卡、节气、内容包 | 没有可扩展的小工具 |
| SOXAI Ring X（计划 399 美元） | App 全部免费；个人免费 API / SDK；主动声明不测血糖血压 | 会员付费；CSV 导出 | 付费理由需说清楚 |
| 华为（运动健康 App，手表端） | 心电分析提示软件获 NMPA 注册证（窦性心律、房颤、早搏提示）；光学“脉搏波心律失常分析”也获注册证；心脏健康研究 | 心电在等注册证 | 缺少不用按电极的被动心律筛查 |

## 四、建议守住不改的

这些地方竞品和我们不同，但全体智能体一致建议保持，它们就是维真的差异。

1. **不打总分**：Oura、WHOOP、三星都用评分；元气与负荷并列、不合成分数，是我们和他们最大的区别。
2. **不估血压、血糖**：WHOOP 的血压估算有争议，SOXAI 把“不测”当成信任卖点；我们只显示血压计和血糖仪的实测值。
3. **戒指无灯、无振动**：桌面小组件就是表盘，提醒一天不超过 2 条。
4. **宋画视觉与光漩**：默认仍显示“两个数字”，光漩作为可选主视觉。
5. **节气只讲时间、风物、节俗，不讲功效**。
6. **基础数据永久免费**：睡眠、元气、负荷、夜间呼吸与血氧不进付费墙。
