# 荷汀 Otio App PRD v1.1（工程版）

Oct 14, 2026 · @Will

## 一、概述与范围

首版做一个配合智能戒指的手机 App：只和用户自己的“平常范围”比，用最少的字告诉他今天怎么样、下一步做什么。交互和文案以原型 v98 为准，本文补充原型里看不到的规则、数据口径和验收标准。

| 项 | 内容 |
| --- | --- |
| 目标用户 | 55–70 岁的长辈（主用户）；30–45 岁的子女（购买者、守护方）；关心作息的中年人 |
| 平台 | iOS 16+、Android 10+；微信小程序只做家人查看（守护） |
| 市场 | 中国大陆（本 PRD）。新加坡改为 To B 单独版本（接诊所 RPM 平台），另有原型和 PRD，不在本文范围 |
| 硬件 | 纤款、心电款两种戒指；手环兼容为 P2 |
| 交互依据 | 原型 v98（单个 HTML，右侧面板可切状态）。原型里标“示意”“内部示意”的内容不上线 |

**品牌**：品牌名定为“荷汀 Otio”（中文名暂定，待商标检索），口号“安时而处顺”，由 BioVision AI 背书，统一写作“by BioVision AI”。助手名“小鸥”（按钮“问小鸥”）。商标检索还没通过，品牌名、英文名、助手名、标志资源全部走配置，不要写死在代码里。标志是两只胖圆鸟（一鸥一鹭）加一荷一莲，荷苞茎上一片荷叶成 t、莲蓬成 i，整体读作 Otio；App 图标用单只小鸥；只用在启动页、欢迎页、关于页、通知、助手入口、配对动画、完成动画、邀请家人和节气报报头，心电、心律提示、复诊一页纸、数据详情页和急症提示不放，鸟的表情不随健康数据变化。见原型 v107。

**首版不做**：血压、血糖估算（只接有注册证设备的实测值）；身体成分；社交排行；心电和心律提示在拿到注册证前只显示说明页。

## 二、信息架构

底部五个页签：今日、身体、计划、守护、我的；“问小鸥”是悬浮按钮。心电和心律提示是唯一需要注册证的模块，入口集中在身体页的健康管理。

## 三、今日页

首页只回答一个问题：今天怎么样、做什么。首屏文字不超过 80 字，没事不写说明，偏离才写。

| 模块（从上到下） | 要求 |
| --- | --- |
| 顶栏 | 日期 · 节气 · 天气；右侧戒指电量。蓝牙断开等特殊状态只在这里出现一次，不重复 |
| 主视觉 | “泼彩光漩”“晷影”“数字”三选一；光漩的浓淡由元气驱动。晷影（v99）：日晷盘，十二时辰刻度，午在上、子在下；晷针影子按本地时间旋转（6:00–18:00 有影，其余只显示月光点）；外圈弧段 = 昨夜入睡到醒来，内圈圆相 = 元气百分比（上限 97%，不画满，无分时为虚线）；点击弹出“今天的晷影”说明；影子只改 transform，不重绘页面 |
| 结论一句 | 如“睡得稳，心跳平。”点开才显示解释 |
| 今天一件事 | 一行，右侧 ＋ 加入计划；夜里变成“现在放下手机” |
| 三个数 | 元气 / 睡眠 / 活动。数字 30px，360px 宽的小屏自动缩小保持一行；下方条表示是否在平常范围 |
| 节气行 | 折叠一行“秋分第 13 天 · 桂花开了”，点开看宜忌。节气当天换成“今日霜降 · 寒露节气报出来了”加小红点，3 天后恢复 |
| 指标列表 | 心率 / 压力（实验） / 夜间呼吸与血氧，右侧短状态。心律提示触发时，心率行改为“连续 3 晚节律不规则”并跳心律页 |

**布局**：白天和夜间只换配色，不换布局和字号。首屏自动填满（原型 fitHome），环的尺寸不超过所在栏宽。

**背景**：山水（默认）、天光、竹影、枯山水、池塘，每种白天、夜里各一版。原型里是 Canvas 程序绘制，正式版改用设计出的位图（@2x/@3x），只有锦鲤、竹叶保留慢动画，系统“减少动态”时全部静止。

**状态**（原型右侧面板可切）：数据齐全、刚配对（前 7 晚建基线）、校准中、数据不足、异常偏离、设备离线、低电量、生病或旅行。每种状态下首页的文案以原型为准。

## 四、身体、计划、守护、我的

### 身体：长期来看我在变好吗

- 结论一句（点开看解释）＋“问小鸥展开说说”。
- 各项指标：元气、睡眠、静息心率、HRV、夜间呼吸、体温偏差。每行右侧短状态，下方一条平常范围条（亮段是平常范围，点是今天）。
- 生物年龄：只来自眼底照片（Eyris，合作方），标“仅供参考”；戒指不重算年龄，只显示两次眼底评估之间哪些生活因素在变。
- 作息规律：近 4 周入睡日历。
- 健康管理：血压、血糖、心电（仅心电款）、夜间心律提示、饮食记录、健康档案。三方设备规则见第五节。
- 复诊一页纸；最下面“往期节气报”一行。

### 计划：今天怎么过

- 天气卡只留天气；时间线按作息生成，已过事项折成一行。
- 固定事项：吃药（来自健康档案，吃完打勾）、测血压（起床后一次、睡前一次）。未到时间的不能显示为已完成。以后可接智能药盒自动打勾。
- 荷息卡：一分钟 · 静心；4-7-8 · 助眠。20:30 后推荐 4-7-8。
- 习惯打卡（应酬喝酒、午后静坐等），只记录对照，不说因果。
- 计划设置：4 步（起睡时间、运动习惯与内容包、连日历、提醒方式），每步可跳过。日历只读“几点到几点有事”，在手机端处理，不上传会议标题。

### 守护：照顾家人，也被照顾

- 家人卡只报持续异常。没事一行“都和平常差不多”；有事一行加粗，如“静息心率连续 3 天高于平常”。
- 可共享项：睡眠、静息心率、夜间呼吸、血压（高于医生定的目标）。**不给数值，不共享吃药、量血压打卡。**
- 超过 2 天没同步：显示“已 2 天没同步”，不猜原因。
- 本人先收到提醒，再通知家人。
- 邀请：6 位邀请码，24 小时有效；对方接受后才开始共享；授权期限 3 个月 / 6 个月 / 1 年，到期自动失效，随时可停。“谁能看到我”显示已接受 / 待接受。
- 固定文案：“这是趋势提醒，不是急救通知。”“荷汀不能发现急症，也不会自动呼救。”

### 我的

一级入口 9 个：顶部名字与会员、戒指卡；外观与小组件、提醒与通知、计划设置、生病或旅行（开关）；数据来源与设备、隐私与数据、钱包与门禁（仅 NFC 款）；实验室、关于。

| 子页 | 内容 |
| --- | --- |
| 外观与小组件 | 首页风格（节气 / 数据 / 简洁，数据完全一样）、背景、首页画面、字号（标准 / 大 / 特大，全 App 生效）、桌面小组件 |
| 提醒与通知 | 见第五节“推送” |
| 隐私与数据 | 家人共享、授权记录、上传夜间原始数据（默认关）、导出（CSV + PDF）、存储地、日历、位置、小鸥记住的内容、健康档案授权、删除账号 |
| 关于 | 品牌、哪些功能有注册证（可点开看证书）、名字的来历（荷汀与 Otio）、荷汀不做的事、五份法律文件、联系我们、页脚出品方与“新加坡设计 · 深圳制造” |

## 五、专项功能

### 荷息（呼吸练习）

| 项 | 一分钟 · 静心 | 4-7-8 · 助眠 |
| --- | --- | --- |
| 节奏 | 吸 5 秒、呼 5 秒，共 6 息，60 秒 | 吸 4、屏 7、呼 8 秒，共 4 组，76 秒 |
| 底部提示 | “吸气时水面起涟漪，呼气时慢慢平下来” | “吸气 4 秒，屏住 7 秒，呼气 8 秒” |
| 印章 | 纳（吸）/ 吐（呼） | 纳 / 定（屏住，圆印）/ 吐 |

- 荷花**匀速**开，练习多长就用多长开足，不跟呼吸停顿。涟漪跟呼吸走。
- 底部提示开始时显示约 2 秒后淡出。
- 做完不出字；小鱼游出时，“再来一组 · 返回”一起出现（做完后约 0.3 秒）。
- 吸、呼切换时手机轻震；系统“减少动态”时画面静止。

### 节气报（不选节气风格时叫半月报）

- 周报已并入，一个节气（约 15 天）一份，节气当天生成。
- 五块：结论一句；节气一句（按城市）；元气 / 睡眠 / 活动三个数（有血压计或用药的加一行“血压在目标内 x/15 天 · 按时吃药 x/15 天”）；和去年同一节气比（第一年和上一节气比）；下个节气一件事。
- 分享在右上角；底部只留“给医生看 · 生成复诊一页纸”。
- 入口：身体页最下面；节气当天首页节气行 + 推送。

### 夜间心律提示 → 心电 → 复诊一页纸（注册证功能）

1. 触发：连续 3 晚光学心率提示节律不规则；一周最多提醒一次。佩戴不足 4 小时的夜不分析。
2. 推送“连续 3 晚，心跳节律有不规则的迹象”；首页心率行、身体页同步变化。
3. 提示页：标出哪 3 晚；写明“这是提示，不是诊断”和可能的误报原因。
4. 分流：**心电款** → “测一次心电”（30 秒单导联，接触不良时计时暂停，连续 10 秒不良结束）；**纤款** → 建议这周内去医院做心电。
5. 心电结果（如“有房颤迹象”）→ “接下来”三步 → 生成复诊一页纸。
6. 复诊一页纸自动加入“夜间心律提示”“心电”两项，标注注册证功能；心电图附第 2 页；用户自己决定发给谁。

每一页都有急症提示：“有胸痛、胸闷，或心慌伴随头晕、出汗、喘不上气，请立即就医或拨打 120。”能提示的心律类型和文案以注册证为准。

### 三方健康设备

- 只接入**持医疗器械注册证**的设备（血压计、连续血糖仪、心电卡等）。
- 经医数云认证的读数参与分析（指南标准显示、关联发现、复诊一页纸、生物年龄），**不计入元气**；未认证的只记录。每条读数标来源设备。
- Apple 健康只读导入。智能药盒为规划中。

### 高原出行（v99）

- **入口**：夜间呼吸与血氧页底部一个开关，用户手动打开；不自动根据定位开启。
- **打开后**：夜间血氧采样加密（间隔由硬件组按续航定）；每天早上在首页给一句话，只拿昨晚的血氧和睡眠跟用户刚打开时的那一晚比。
- **不做**：不报警、不判断高原反应或身体状况，文案不写“预防”；页面固定一句“感到不舒服请及时就医”。
- **关闭**：用户手动关，或连续 3 晚数据回到开启前的常见范围后提示可以关闭（具体规则 A14 定）。这段时间的数据不计入个人基线。
- **合规**：不出现宗教、地域文化符号，配图只用普通山形图标。

### 推送（“提醒与通知”一页管）

| 类型 | 触发 | 默认 |
| --- | --- | --- |
| 夜间心律提示 | 见上；安静时段内第二天早上补发 | 开，建议常开 |
| 吃药、测血压 | 计划里的时间 | 开 |
| 计划提醒 | 运动、早睡等 | 开 |
| 节气报 | 节气当天一条 | 开 |
| 家人提醒 | 家人某项连续 3 天偏离 | 开 |

安静时段跟着作息走（默认 23:00–7:00）。戒指没有振动，提醒都走手机。

## 六、数据与算法口径

所有判断只和用户自己的平常范围比，不和人群比。下表是产品口径，具体窗口长度和阈值由算法组定稿，标“建议”的是待确认值。

| 概念 | 口径 |
| --- | --- |
| 基线 | 戴满 7 晚后才出现平常范围；之前显示“建立基线中” |
| 平常范围 | 按近期个人数据滚动计算（建议近 30 天）；前端只显示“亮段 + 今天的点” |
| 元气 | 0–100 的综合分，只用戒指数据。三方设备读数不计入（避免元气被定性为医疗器械软件） |
| 负荷 | 和元气分开看；生病或旅行时暂停负荷目标 |
| 持续异常 | 同一项连续 3 天离开平常范围（血压：连续 3 天高于医生定的目标）。用于首页、身体页和守护 |
| 生病或旅行 | 用户手动标记；这段数据不计入基线 |
| 换戒指 | 趋势图上竖线标出；约 2 周校准完成 |
| 家人没同步 | 超过 2 天无数据即提示，不显示“差不多” |
| 夜间心律 | 佩戴不足 4 小时的夜不分析；连续 3 晚触发；一周最多一次 |
| 习惯对照 | 只说“打卡的那几晚和平常比”，必须附“只是对照，不代表因果” |
| 生物年龄 | 只来自眼底评估；戒指不生成年龄数字 |

**数据同步**：戒指 → 手机（BLE）→ 服务端。新数据到达后刷新首页；离线时显示上次同步时间，不假装有新数据。

## 七、合规与隐私要求

以下为硬性要求，上线前由 A13 逐条验收。

**注册证功能要能远程开关**

- 心电、夜间心律提示各自一个开关，按**地区 + 戒指款式 + 注册证状态**三个条件决定（原型 FLAGS()）。
- 未获批：只显示说明页；心电可在“实验室”记录但不显示结果。
- 获批后：能提示的心律类型、文案、适用人群只按注册证；文案走配置下发，不写死。
- “关于”页和复诊一页纸上标注哪些是注册证功能，其余写“非医疗器械，仅供日常健康参考”。

**文案禁区**

- 不诊断：只说“迹象”“和平常比”，不说“患有”“确诊”。
- 禁用词：无病、无病息灾、养生、调理、预防、守护健康、最小、最轻（对比类须附依据并经 A13 审）。
- 家人守护不承诺急救；不自动呼救。
- 血压很高时提醒就医（如 180/110）**首版不做**，等 A13 判断是否需按医疗器械管理。

**隐私（中国个人信息保护法 / 新加坡 PDPA）**

- 健康数据为敏感个人信息：单独同意；家人共享按项授权、对方接受后生效、有期限、可随时撤回。
- 数据分地存储：中国用户存中国境内，新加坡用户存新加坡；“隐私与数据”里显示存储地。
- 必须可见：用户协议、隐私政策、个人信息收集清单、与第三方共享清单、开源许可。
- 用户可导出（CSV + PDF）、可删除账号和全部数据。
- 埋点只记录行为（如打开早报），不采集任何健康数值。
- 日历在手机端处理，不上传会议标题；位置只用于天气和节气内容。
- 上传夜间原始数据用于算法改进：默认关，去标识后存储。

## 八、非功能需求

| 类别 | 要求 |
| --- | --- |
| 字号 | 六级字号；正文不小于 15px，13px 只用于同步时间、日期等辅助信息；首页三个数 30px、标签 15px |
| 无障碍 | 支持系统字体缩放和 App 内字号（标准 / 大 / 特大）；开关、分段控件有读屏标签；可点区域不小于 44×44；“减少动态”时所有动画静止 |
| 对比度 | 白天、夜间两套配色，文字不加发光特效；任何背景上正文对比度达 WCAG AA |
| 色彩含义 | 偏离用元气色小圆点和加粗，不用红绿表示好坏 |
| 性能 | 冷启动到首页可读 ≤ 2 秒（建议值）；背景图按屏幕密度加载；荷息动画 60fps |
| 离线 | 无网时可看已同步的数据和荷息；联网后补传 |
| 地区 | 地区决定：注册证功能、数据存储地、节气内容（上海 / 北京 / 新加坡各一套）、邀请渠道（中国加微信小程序） |
| 语言 | 首版简体中文；新加坡版加英文（B6 出文案）。所有文案走多语言资源，不写死 |
| 品牌配置 | 品牌名、英文名、助手名、口号、图标都从配置读，改名不动代码 |
| 视觉依据 | 以原型 v98 为准；配色、圆角、毛玻璃卡片等变量见原型 CSS（:root 与 .app.xuan / .app.mo） |

## 九、优先级与验收标准

排期日期由工程组评估后回填。P0 是首版上线的必须项。

| 优先级 | 范围 |
| --- | --- |
| P0 | 配对与同步；今日页（全部 8 种状态）；身体页指标与趋势；计划页（含吃药、测血压）；荷息两种；我的页及外观、提醒与通知、隐私与数据、关于；推送框架；注册证功能开关（未获批状态）；导出与删除账号 |
