# 荷汀戒指 · 工业设计与 ODM 需求

Oct 21, 2026 · @Will

## 背景与目标

这份需求要 ODM 和工业设计在一轮打样里定下三件事：正面记号（兼天线窗）、内圈材质、长辈能自己戴好的尺码与外形。

- **产品定位：** 荷汀（Otio）戒指配合 App，先服务一个人住的长辈和照看他们的家人，在新加坡连诊所做远程监测；同时兼顾年轻用户的睡眠和运动场景。
- **和竞品的差别：** 珠宝质感的戒指市场已经出现（如 ISHO Ring：钛合金内外圈、正面蓝宝石窗）。我们不拼参数，拼三点：东方记号、长辈好戴、设备接上诊所。
- **设计原则：** 少就是多；记号既是装饰也是功能（天线窗、朝向提示）；所有健康功能的说法以注册证为准。

概念草图见下一节，只用来选方向，不是最终渲染。

## 正面记号（兼天线窗）

正面留一块非金属窗：给蓝牙信号出口，也告诉佩戴者“这面朝外”。三个方向各打样 3 枚，实测后定一个主力款。

&#91;image: 荷汀戒指正面记号概念草图：三种记号 × 三种配色，及佩戴提示\]

| 方向 | 材质与工艺 | 好处 | 风险 | 定位 |
| --- | --- | --- | --- | --- |
| A 莲子窗 | 蓝宝石盖板，下衬石青珐琅 | 工艺成熟；颜色和 App 一致；一眼认出朝向 | 珐琅色差要控 | 主力款（推荐） |
| B 荷叶纹 | 月白底，激光刻荷叶脉络 | 最含蓄、最像首饰 | 小面积刻纹良率；弱光下不易辨朝向 | 限量款 |
| C 青瓷嵌件 | 青瓷色陶瓷，极淡冰裂纹 | 玉感温润，长辈接受度高 | 陶瓷易碎，要过跌落和撞击 | 长辈礼盒款 |

**要求**

1. 窗口是天线的主要出口：ODM 给出三种材质各自的信号实测（见验收）。
2. 窗口居中，竖向胶囊形；尺寸由 ODM 按天线需要定，但要大到一眼能看见。
3. 与外壳齐平，边缘倒圆，不勾衫线、不卡泥。
4. 不设发光的提示灯（长辈会误以为是报警）；充电状态由充电座显示。

## 外壳与内圈材质

外壳定钛合金；内圈请 ODM 做两个方案对比，我们按对比结果决定旗舰款和标准款各用哪个。

| 对比项 | 全钛（内外同材） | 钛外壳 + 树脂内圈 |
| --- | --- | --- |
| 手感与高级感 | 待 ODM 评估 | 待 ODM 评估 |
| 传感器开窗工艺与良率 | 待报 | 待报 |
| 蓝牙信号（配合正面窗） | 待实测 | 待实测 |
| 体温传感响应 | 待实测 | 待实测 |
| 重量（以 US 9 号为准，克） | 待报 | 待报 |
| 续航影响 | 待报 | 待报 |
| 单件成本（1 万件量） | 待报 | 待报 |

- 内圈一律做“舒适弧面”，两侧边缘大倒角（见尺码与人体工学）。
- 内侧传感器窗口与内圈齐平或微凸不超过 0.3 mm（待 ODM 确认可行值），长时间佩戴不压出印子。
- 表面涂层和内圈材料要提供皮肤接触的生物相容性报告。

## 传感器与功能清单

App 已经按下表设计；每一项请 ODM 标明“已有 / 可做 / 不支持”和注册状态。带“等注册证”的功能，App 里现在显示“即将开放”。

| 功能 | App 里的位置 | 传感器 | 注册要求 |
| --- | --- | --- | --- |
| 静息心率、HRV、元气 | 首页、身体页 | PPG | 健康参考 |
| 睡眠、作息规律 | 首页、身体页 | PPG + 加速度 | 健康参考 |
| 夜间呼吸频率 | 身体页 | PPG 推算 | 健康参考 |
| 夜间血氧 | 身体页、血氧页 | PPG（红光 + 红外） | 希望取得脉搏血氧仪注册 |
| 体温变化 | 元气计算、趋势 | 皮肤温度 | 健康参考 |
| 步数、距离 | 首页、活动趋势 | 加速度 | 健康参考 |
| 夜间心律提示 | 检查与测量 | PPG | 等注册证 |
| 睡眠呼吸提示 | 检查与测量 | PPG + 血氧 | 等注册证 |
| 血压趋势 | 检查与测量 | PPG（要用袖带血压计校准） | 等注册证 |

**要求**

1. 提供原始数据和算法输出的 SDK 或接口文档，支持 iOS 和 Android。
2. 固件支持空中升级（OTA）。
3. 续航、防水等级、充电方式请 ODM 报实际值。
4. 列出 ODM 已有或在办的注册（中国 NMPA、新加坡 HSA、欧盟 CE、美国 FDA），写清每张证覆盖哪些功能。

## 尺码与长辈人体工学

长辈指关节粗、手指不灵活，尺码和内圈形状要保证他们能自己戴上、摘下。

- **尺码范围：** 至少覆盖到大号（具体范围由 ODM 按模具成本提方案）；大号不能只是放大，传感器位置要重新校。
- **舒适弧面：** 内圈做轻微外凸的弧面，两侧大倒角，套过指节时不卡。
- **朝向：** 正面记号和内侧传感器上下对齐；佩戴口诀只有一句“记号朝上就对了”，说明卡和 App 配对页都用它。
- **指模套装：** 购买前寄出，和正式戒指外形、内径一致，戴满 24 小时再选尺码；新加坡另在合作诊所和药房放实体量圈。
- **换尺码：** 长辈手指会随天气和药物肿胀，建议提供一次免费换号（待运营确认成本）。

## 配色与表面处理

三种配色用传统色命名，每种色做抛光和拉丝两种表面打样。

| 配色 | 给谁 | 表面 | 说明 |
| --- | --- | --- | --- |
| 赤金 | 子女送父母 | 抛光 / 拉丝 | 主打孝心礼物；配礼盒和指模套装 |
| 玄色 | 年轻人 | 哑光 / 拉丝 | 耐磨、不显划痕 |
| 月白 | 中性 | 抛光 / 拉丝 | 银白偏冷，配 A 莲子窗最显 |

- 抛光面好看但易划花，长辈戴久显旧；请 ODM 报两种表面的耐磨测试结果。
- 金色请给出色差标准和薄膜工艺（PVD 等），保证批次一致。

## 验收测试项

打样件过完下面这些项才进入下一轮；具体通过标准由 ODM 先报，我们确认。

**信号与测量**

- [ ] 三种正面窗材质各自的蓝牙连接距离和稳定性（手握拳、手伸进被子两种姿势）
- [ ] 全钛与树脂内圈的心率、血氧、体温准确度对比
- [ ] 打样件续航实测

**结构与外观**

- [ ] 跌落和撞击（C 青瓷嵌件重点）
- [ ] 防水：洗手、洗澡、游泳
- [ ] 表面耐磨与汗液腐蚀（拉丝 / 抛光对比）
- [ ] 金色批次色差

**长辈试戴（我们组织，在新加坡招募 60 岁以上用户）**

- [ ] 有关节炎的用户能否不靠别人自己戴上、摘下
- [ ] 不提示的情况下能否戴对朝向（三种记号各测）
- [ ] 洗手、洗澡时会不会滑落
- [ ] 连戴一周的舒适度和压痕

## 交付物、节奏与待确认问题

分三轮走，每轮结束我们做一次决定；具体日期等 ODM 报工期后定。

1. **第一轮 · 方案：** ODM 回复传感器清单、注册情况、内圈两方案对比表、三种正面窗的工艺可行性和报价。
2. **第二轮 · 打样：** A/B/C 各 3 枚、两种内圈各 3 枚，配指模套装；跑完验收里的信号和结构项。
3. **第三轮 · 试戴：** 我们在新加坡做长辈试戴，定主力款、礼盒款、限量款和尺码表。

**待确认**

- [ ] 选定哪家 ODM；他们已有哪些注册证
- [ ] 正面窗最终尺寸（取决于天线）
- [ ] 尺码范围和模具数量
- [ ] 旗舰款是否全钛
- [ ] 目标零售价和成本上限
- [ ] 礼盒和指模套装的设计由谁负责
