# Otio 荷汀 · 戒指 + App 项目资料

这里汇总了 Otio 荷汀 App 原型的代码和项目文档。原型是单个 HTML 文件，用浏览器打开就能操作（推荐 Chrome），不需要安装任何东西。

在线版（新加坡版，持续更新）：https://claude.ai/artifact/QMF26HTqXDfAXWDNQZr9ns

## 目录

| 文件夹 | 内容 |
| --- | --- |
| `原型/新加坡版/` | 当前版本 v3.8.39，单文件 HTML。左侧是演示面板：语言、自己用/连诊所、演示场景、时间、墨圈颜色、光漩笔法、家人捎话等 |
| `原型/国内版/` | 国内版原型当前工作稿 |
| `原型/历史版本/新加坡版/` | 关键节点：v3.8 基线、v3.10 大改版（已回退）、v3.8.26、v3.8.33、v3.8.38 |
| `文档/` | PRD、ODM 需求、设计理念、品牌素材、硬件方案与调研、商标材料、历史原型（从 claude.ai 导出） |
| `设计/` | 戒指正面记号概念草图、首页版本对比截图、草图绘制脚本 |
| `开发/测试脚本/` | Playwright 自动测试：打开所有页面查错、各状态截图 |
| `开发/补丁脚本/` | 每次修改原型用的 Python 补丁，按文件名对应改动内容，可当修改记录看 |

## 原型的修改记录

每个版本改了什么，写在原型左侧面板的更新说明里（中英文）。

## 怎么跑测试

需要 Node.js、Python 3 和 Playwright：

```
npm i -g playwright
npx playwright install chromium
bash 开发/测试脚本/run_sweep.sh
```

`run_sweep.sh` 会把当前新加坡版复制成测试版（注入 `window.__t`），在“自己用”和“连诊所”两种模式下打开全部页面，没有脚本错误时输出 `no errors`。其他脚本（`st.js` 首页各状态、`vt.js` 墨圈、`art2.js` 笔法对比等）用法相同：先 `python3 make_test.py <原型> sw_test.html`，再 `node <脚本> "$PWD/sw_test.html"`，截图输出到当前目录的 `otiagen/`、`sw/`。

## 工作约定

- 一页一页审，先给建议，批准后再改；只修逻辑错误和静态数据，不擅自改版。
- 少就是多、低认知负荷、适合长辈；不做诊断，紧急情况写 995，按 PDPA 处理数据。
- 小鸥是吉祥物，不改。眼底筛查只在机构版出现。
- 没拿到注册证的功能（夜间心律提示、睡眠呼吸提示、血压趋势）一律显示“即将开放 · 在等注册证”。
